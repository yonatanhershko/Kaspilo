# Language and RTL rules

- Languages: Hebrew (`he`, RTL) and English (`en`, LTR).
- First launch: Hebrew phone → `he`. Any other phone language → `en`. The user can change it in More → Language; that choice is saved and wins.
- No hard-coded user-facing strings in components. Every string comes from `apps/mobile/src/i18n/{he,en}.json`. Add both languages in the same change.
- Layout never mirrors (owner decision 2026-11-15): the app is always laid out left-to-right on iPhone and Android, so Hebrew and English look the same. Native RTL is switched off (`I18nManager.allowRTL(false)`).
- Language only changes text and icon/text row order. All text goes through `AppText`, which starts Hebrew at the right and English at the left (centered text stays centered). In Hebrew it opens every line with an RLM, so a line that starts with a Latin word (the app name "Kaspilo …", "• Kaspilo …") still reads right to left on iPhone and Android. Text that is only a number (amount, date, time, phone) is always left-aligned and left-to-right, in both languages; `AppText` detects it. Number inputs (amount, budget, deposit, month start day, counts) are the exception (owner 2026-11-18): in Hebrew they start at the right, in English at the left; the digits still read left to right and the sign stays left of the number. Typed text moves the cursor with it: email, password and code fields start by the app language (Hebrew right, English left; their content still reads left to right) (owner 2026-11-21, was "always at the left"); other text fields start by the first letter typed (Hebrew right, English left), empty fields by the app language (owner 2026-11-19). The password eye sits across from where typing starts: Hebrew at the left, English at the right. The currency sign sits left of the number. Rows of icon + text use `useRowAlign()` from `@/i18n` (Hebrew: icon at the right). Never hand-roll `textAlign` / `flex-row-reverse` in a screen.
- Direction icons (back chevron, arrows) keep their left-to-right meaning. Numbers, currency amounts and charts never flip.
- Changing the language needs no app reload.
- Dates and numbers format with `Intl` using the active locale.
- Admin web is English only for now.
